# Развёртывание на сервере

Архив `build/perfect-front-deploy.tar.gz` содержит production-сборку `.next`,
изображения `public` и исходники для повторной сборки. Зависимости, секреты
и кеш сборки в архив не входят.

## Установка и запуск

Нужен сервер с Node.js 22 LTS и npm. Распакуйте архив в отдельный каталог приложения:

```sh
mkdir -p perfect-front
tar -xzf perfect-front-deploy.tar.gz -C perfect-front
cd perfect-front
npm ci --include=dev
cp .env.example .env.local
```

Заполните `.env.local` настоящими настройками SMTP перед запуском.
Без них отправка заявок в production возвращает 503.

Архив собран на macOS. На Linux выполните сборку заново после установки
зависимостей, чтобы получить результат для платформы сервера:

```sh
npm run build
npm start -- --hostname 127.0.0.1 --port 3000
```

Команда запуска работает в текущем терминале. Для постоянной работы настройте
её как службу systemd или в используемом на сервере менеджере процессов,
с рабочим каталогом приложения и `NODE_ENV=production`.
Настройте Nginx или другой reverse proxy на `http://127.0.0.1:3000`
и HTTPS для домена. Сайт содержит API заявок и серверные редиректы,
поэтому для работы требуется процесс Node.js.

## Проверка

При работающем сервере, в другом терминале из каталога приложения:

```sh
npm run test:smoke
```

Проверка не отправляет реальные письма. Доставку заявки проверьте отдельно
через форму после настройки SMTP. Канонические URL и sitemap настроены
на `https://perfecthouse.spb.ru`; при смене домена обновите их в исходниках
и пересоберите приложение.
